AQA 7408 · 3.3.2.3 · total internal reflection and step-index fibres

Why have cladding? It protects the core surface from scratches (which would let light escape), keeps the signal inside the core so it cannot cross into a touching fibre (crosstalk, security), and a cladding n only slightly below the core n gives a large critical angle, so only rays close to the axis are guided, which reduces modal dispersion.

Reduce modal dispersion: use a very narrow core (single-mode fibre) so there is only one path; or a cladding with n close to the core's. Reduce material dispersion: use monochromatic light. Absorption reduces the amplitude; repeaters (amplifiers) restore it. Broadening limits how close together pulses can be, so it limits the data rate.
