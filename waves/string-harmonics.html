AQA 7408 · 3.3.1.3 · stationary waves on strings, microwaves and sound
f = (1/2l) √(T/μ) (first harmonic)

The string has l = 1.20 m, T = 7.2 N, μ = 1.25 × 10−3 kg m−1. Slowly increase the signal generator frequency and find the frequencies where a large stationary wave forms.

The wave reflects from the plate and superposes with the incoming wave, so a stationary wave forms. Move the probe and count the minima (nodes). Distance between adjacent nodes = λ/2. Measure across several nodes to reduce the uncertainty, then use c = fλ.
